# All Around Africa — Website

Static pages for the OAuth approval of the application "All Around Africa Pipeline":
home, privacy policy, terms of service, legal notice (Impressum).

This folder is its **own Git repository**, separate from the pipeline and its
`instanz\` folder. That is intentional: the pipeline folders contain `.env` and
`secrets\`, and this website is public.

## URLs for the Google Cloud Console (Branding)

| Field | URL |
|---|---|
| Application home page | `https://hishembourisha.github.io/all-around-africa-site/` |
| Privacy policy | `https://hishembourisha.github.io/all-around-africa-site/privacy.html` |
| Terms of service | `https://hishembourisha.github.io/all-around-africa-site/terms.html` |
| Authorized domain | `hishembourisha.github.io` |

`github.io` alone is not accepted: it is on the Public Suffix List. The full
subdomain is.
