1. Controller

The controller within the meaning of the GDPR is the operator of the channel “All Around Africa”. Full contact details are given in the Legal Notice. Email: fbabouricha@gmail.com

2. This website

This website consists of static pages served by GitHub Pages. It sets no cookies, uses no analytics or tracking services and loads no third-party fonts or scripts. When pages are requested, the host GitHub Inc. processes technically necessary connection data such as IP address, time and requested file in server logs. The legal basis is Art. 6(1)(f) GDPR (legitimate interest in secure operation). Details: GitHub Privacy Statement.

3. The application “All Around Africa Pipeline”

The application is a private automation tool of the operator. It runs on the operator's own server and has exactly one user: the operator. There is no registration, there are no user accounts and no data is processed on behalf of third parties.

3.1 Access to Google and YouTube data

To upload videos, the application signs in to the operator's YouTube channel via OAuth 2.0 and requests the following permissions:

ScopeWhat it is used for
youtube.upload Uploading the generated video file to the operator's own YouTube channel.
youtube.force-ssl Setting the thumbnail, title, description and visibility of the operator's own videos, posting one comment by the channel under its own video, maintaining the channel's own description and branding, and reading the channel's own video list and public statistics to verify uploads and avoid repeating topics.

No further access takes place. The application does not read viewer data, comments by third parties, subscriber lists or YouTube Analytics reports.

3.2 Storage of access credentials

After the one-time sign-in, the application stores the OAuth token issued by Google only locally in the file system of the operator's server, readable only by the operator's account. The token is not transmitted, not shared with third parties and not written to any database or cloud service. Its sole purpose is to perform subsequent uploads without signing in again.

3.3 Sharing

Data obtained from Google is not shared with third parties, not sold, not used for advertising and not used for profiling. It is not read by humans except where necessary to troubleshoot the operator's own system, with the operator's explicit consent, or where required by law.

3.4 Limited Use

All Around Africa Pipeline's use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

3.5 Deletion and revocation

Access can be revoked at any time at myaccount.google.com/permissions, which invalidates the token immediately. In addition, the locally stored token file can be deleted on the server; the application then loses all access to the YouTube channel. No copies remain.

4. Sources processed

To create the videos, the application retrieves publicly available RSS feeds, articles and public search results. No personal data of users of those services is collected. To generate script, narration and imagery, text content is sent to the APIs of Anthropic, OpenAI and fal.ai; it contains no personal data of the operator or of third parties, except where such data is the subject of the respective public report.
